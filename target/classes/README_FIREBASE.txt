De ket noi Cloud Firestore chung voi du an FootballBookingAndroid:
1. Vao Firebase Console -> Project Settings -> Service accounts -> Generate new private key.
2. Doi ten file JSON tai ve thanh: serviceAccountKey.json
3. Dat file vao thu muc goc D:\SmartCard\serviceAccountKey.json (hoac thu muc src/main/resources/).
4. Khoi dong lai ung dung NetBeans.
